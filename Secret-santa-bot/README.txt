SECRET SANTA BOT
================

Discord-бот для игры в «Тайного Санту». Организатор создаёт событие, участники присоединяются и оставляют вишлист, бот проводит жеребьёвку и в личных сообщениях сообщает каждому, кому он дарит подарок. Санта и подопечный могут переписываться через бота анонимно.


ВОЗМОЖНОСТИ
-----------

- События: название, бюджет и дата. На сервере может быть несколько событий одновременно.
- Участие: вход и выход из события, вишлист для каждого участника.
- Жеребьёвка: каждый получает ровно одного подопечного, а сам себе подарок не дарит. Санта получает в личные сообщения ник, аватар и вишлист подопечного.
- Обновление вишлиста: если подопечный изменил вишлист после жеребьёвки, его Санта получает уведомление.
- Анонимный чат: Санта пишет подопечному, подопечный пишет Санте. Имя отправителя не раскрывается.
- Меню организатора: список участников, список пар, запуск жеребьёвки, смена бюджета, удаление события.
- Всё через кнопки. Единственная текстовая команда - !menu, она выводит главное меню.


ТРЕБОВАНИЯ
----------

- Node.js 18 или 20 (LTS). Зависимость better-sqlite3 версии 8 не имеет готовых сборок для Node 22 и новее.
- Токен Discord-бота (инструкция ниже).


УСТАНОВКА
---------

1. Установите зависимости:

   npm install

2. Создайте файл .env рядом с index.js (за основу возьмите .env.example):

   # Токен вашего бота
   TOKEN=ваш_токен

   # Префикс текстовой команды (используется только для !menu)
   PREFIX=!

3. Запустите бота:

   npm start

При успешном старте в консоли появится строка «Готово: <имя бота>». База данных santa.sqlite создаётся автоматически при первом запуске.


НАСТРОЙКА БОТА В DISCORD
------------------------

1. Откройте Discord Developer Portal (https://discord.com/developers/applications) и создайте приложение (New Application).
2. Перейдите во вкладку Bot, нажмите Reset Token и скопируйте токен в .env.
3. Там же, в блоке Privileged Gateway Intents, включите Message Content Intent. Без него бот не увидит команду !menu.
4. Во вкладке OAuth2 -> URL Generator выберите scope "bot" и права:
   - View Channels
   - Send Messages
   - Manage Roles (нужно, чтобы выдавать роль организатора)
5. Откройте сгенерированную ссылку и добавьте бота на сервер.

Важно: роль Santa ADM бот создаёт сам. Чтобы он мог её выдавать, роль бота должна быть выше Santa ADM в списке ролей сервера. Сама роль не даёт никаких прав в Discord, это лишь пропуск в меню организатора.


КАК ПОЛЬЗОВАТЬСЯ
----------------

В любом текстовом канале отправьте !menu. Бот пришлёт главное меню с кнопками.

Кнопки для участника:

- Присоединиться - выбрать событие и сразу заполнить вишлист.
- Мой вишлист - изменить вишлист (можно и после жеребьёвки, Санта получит уведомление).
- Показать моего подопечного - повторно получить в личные сообщения данные подопечного.
- Написать подопечному - анонимное сообщение подопечному.
- Написать Санте - анонимное сообщение своему Санте.
- Выйти - выйти из события (только до жеребьёвки).

Кнопки для организатора:

Любой участник сервера может нажать «Создать событие». Создатель автоматически получает роль Santa ADM и доступ к кнопке «Меню Организатора»:

- Просмотр участников - присылает список участников в личные сообщения.
- Просмотр пар - присылает в личные сообщения, кто кому дарит. Спойлер для организатора!
- Начать жеребьёвку - разыгрывает пары и рассылает сообщения сантам.
- Изменить бюджет - меняет бюджет события.
- Завершить событие - удаляет событие, участников и пары (с подтверждением).

Типичный сценарий:

1. Организатор создаёт событие.
2. Участники нажимают «Присоединиться» и пишут вишлист.
3. Когда все собрались, организатор запускает жеребьёвку.
4. Каждый Санта получает в личные сообщения данные подопечного и покупает подарок в рамках бюджета.
5. После праздника организатор завершает событие.


ВАЖНО ЗНАТЬ
-----------

- Жеребьёвка проводится один раз. Повторный запуск заблокирован, чтобы люди не получили разных подопечных. Чтобы провести её заново, удалите событие и создайте новое.
- После жеребьёвки нельзя входить в событие и выходить из него. Иначе пары «разъедутся».
- Нужны минимум 2 участника.
- У всех участников должны быть открыты личные сообщения от участников сервера. Если сообщение не доставилось, бот напишет в общий канал, что пользователю нужно открыть DM. Данные подопечного всегда можно запросить повторно кнопкой «Показать моего подопечного».
- Анонимность: имена в анонимных сообщениях не раскрываются, а ошибки доставки не попадают в общий канал. Единственный, кто видит все пары, - организатор через «Просмотр пар».
- Общий канал: для служебных объявлений (ошибки доставки, удаление события) бот использует системный канал сервера, а если его нет - первый доступный текстовый канал.
- Лимиты: вишлист и анонимное сообщение - до 1000 символов. В выпадающих списках показываются первые 25 событий.

ДАННЫЕ
------

Всё хранится в файле santa.sqlite рядом с index.js (таблицы events, participants, pairs). Для резервной копии достаточно скопировать этот файл при остановленном боте.


РЕШЕНИЕ ПРОБЛЕМ
---------------

Бот не отвечает на !menu
  Проверьте, включён ли Message Content Intent, есть ли у бота доступ к каналу, совпадает ли PREFIX в .env.

«Не удалось выдать роль Santa ADM»
  У бота нет права Manage Roles или его роль ниже Santa ADM.

Ошибка при npm install, "invalid ELF header" или "NODE_MODULE_VERSION"
  Используйте Node 18 или 20 и переустановите зависимости: удалите папку node_modules и выполните npm install.

Санта не получил сообщение
  У участника закрыты личные сообщения. Пусть откроет их и нажмёт «Показать моего подопечного».

Бот не запускается, TOKEN пустой
  Файл .env должен лежать рядом с index.js и называться именно .env.


БЕЗОПАСНОСТЬ
------------

- Никогда не публикуйте .env и santa.sqlite (они уже добавлены в .gitignore).
- Если токен случайно попал в чужие руки, сразу сбросьте его в Developer Portal (Reset Token) и обновите .env.
